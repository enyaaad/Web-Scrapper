# Web-Scrapper

Программа для скачивания веб-страниц со всеми зависимыми ресурсами и их последующей обработки. Создает локальную копию сайта с оптимизированным кодом.

## Назначение

Программа предназначена для:
- Скачивания веб-страниц вместе со всеми ресурсами (изображения, стили, скрипты, шрифты)
- Оптимизации HTML и CSS кода
- Подготовки страниц для дальнейшего использования с добавлением аналитики и автодоменов

## Технологии

- **Go** - основной язык программирования
- **goquery** - библиотека для парсинга HTML
- **golang.org/x/net/html** - парсинг и рендеринг HTML

## Структура проекта

```
Web-Scrapper/
├── cmd/
│   └── main.go              # Точка входа
├── internal/
│   ├── downloader/          # Загрузка ресурсов
│   ├── parser/              # Парсинг CSS файлов
│   ├── refactor/            # Рефакторинг HTML/CSS
│   └── utils/               # Вспомогательные функции
└── go.mod                   # Зависимости
```

## Логика работы

### 1. Загрузка страницы
Программа получает HTML документ по указанному URL и парсит его с помощью goquery.

### 2. Скачивание ресурсов
Последовательно загружаются все зависимые ресурсы:
- **Изображения** - из тегов `<img>` и CSS файлов
- **Стили** - все файлы CSS, включая встроенные шрифты
- **Скрипты** - JavaScript файлы
- **Шрифты** - извлеченные из CSS файлов

Все ресурсы сохраняются в соответствующие папки: `images/`, `styles/`, `script/`, `fonts/`.

### 3. Нормализация URL
Относительные URL преобразуются в абсолютные с учетом базового домена. Для каждого типа ресурса используется своя логика нормализации.

### 4. Рефакторинг HTML
- Удаление ненужных скриптов (аналитика, реклама)
- Оптимизация атрибутов изображений (добавление lazy loading)
- Удаление лишних атрибутов у скриптов

### 5. Рефакторинг CSS
- Замена путей к ресурсам на относительные
- Очистка неиспользуемых стилей через внешний API
- Оптимизация путей к изображениям и шрифтам

### 6. Добавление дополнительного функционала
- Вставка GTM кода для аналитики
- Добавление PHP кода для работы с автодоменами

## Использование

1. Установите зависимости:
```bash
go mod download
```

2. Отредактируйте `cmd/main.go` и укажите URL страницы для скачивания:
```go
const webpageURL = "https://example.com/page"
```

3. Запустите программу:
```bash
go run cmd/main.go
```

4. Результат будет сохранен в текущей директории:
- `index.html` - главная страница
- `images/` - изображения
- `styles/` - CSS файлы
- `script/` - JavaScript файлы
- `fonts/` - шрифты

## Особенности

- Параллельная загрузка ресурсов для ускорения процесса
- Автоматическое создание необходимых директорий
- Обработка различных форматов URL (относительные, абсолютные, протокол-относительные)
- Извлечение ресурсов из CSS файлов
- Очистка неиспользуемого CSS кода

## Требования

- Go 1.25.5 или выше
